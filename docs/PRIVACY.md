# Spectrum ハイウェイ プライバシーポリシー

最終更新日: 2026 年 11 月 1 日

Spectrum ハイウェイ（以下「本アプリ」）は、再生中の音楽の情報とスペクトラムアナライザーを表示し、走行中の高速道路・有料道路などでは前方の IC・JCT・SA・PA までの距離と到着予定時刻を表示するアプリです。本アプリが扱う情報と、その使い方は次のとおりです。

## 1. 端末の中だけで使う情報

| 情報 | 使い方 |
|---|---|
| 位置情報（GPS など） | 走行中の道路と進行方向を判定し、前方の施設までの距離・到着予定時刻を計算します。走行中は、画面を消しても計算を続けるために常駐サービスで位置情報を使います。 |
| 端末のセンサー（ジャイロ・加速度・方位） | 進行方向の判定とトンネル内の位置推定に使います。 |
| 車両の情報（Android Auto 接続時。車速・ETC カードの状態・燃料／電池残量・車両のジャイロや位置） | 速度・位置の推定、ETC カード未挿入の警告、給油・充電の案内に使います。 |
| 運転傾向の学習結果・設定・自分で登録したオービス地点 | 端末内に保存し、到着予定時刻の計算と表示に使います。 |
| 再生中の音（マイクの権限） | 端末で再生中の音の大きさを周波数ごとに解析し、スペクトラムアナライザーとして表示します。音声の番号を知らせない音楽アプリでは、再生中の音声を見つけるために、端末内の音声ごとに音の大きさだけを短時間測ります。いずれも音声を録音・保存することはありません。 |
| 再生中の曲の情報（通知へのアクセス） | 音楽アプリの再生情報・通知から、曲名・アーティスト・アルバム・ジャケット画像・再生位置を読み取って表示し、再生・一時停止・曲送りの操作に使います。音楽以外の通知の内容は、曲情報の取得元を選ぶ診断画面に表示するだけで、保存しません。 |
| 再生中の音声の番号（任意の DUMP 権限） | 利用者が Shizuku などで許可した場合に限り、端末の音声の状態からアプリごとの音声の番号を読み取り、スペクトラムアナライザーの解析対象を選ぶために使います。 |

これらの情報は端末の外へ送信せず、開発者が受け取ることもありません。

## 2. 外部のサービスへ送る情報

本アプリは、次の場合にだけ外部のサービスと通信します。

- **地図データの取得**：地図データ（OpenStreetMap をもとに作成）を GitHub または Overpass API のサーバーからダウンロードします。オンライン取得を使う場合、取得したい範囲（地図の区画）を問い合わせます。
- **渋滞情報（設定した場合のみ）**：利用者が選んだ提供元（HERE、TomTom、Google のいずれか）へ、利用者自身が登録した API キーと、前方の道路の位置（座標）を送り、渋滞・事故・通行止めの情報を受け取ります。送った情報の扱いは各提供元のプライバシーポリシーに従います。

これらの通信で、氏名・メールアドレス・端末の識別子などを本アプリが送ることはありません。

## 3. 広告・解析

本アプリは広告を表示せず、利用状況の解析ツールやクラッシュ報告ツールも組み込んでいません。

## 4. 保存と削除

情報はすべて端末内（本アプリの保存領域）に保存されます。本アプリをアンインストールすると削除されます。渋滞情報の API キーは、設定画面からいつでも削除できます。

## 5. お問い合わせ

本アプリについてのお問い合わせは、本アプリのソースコードを公開している GitHub リポジトリの Issues からお寄せください。
