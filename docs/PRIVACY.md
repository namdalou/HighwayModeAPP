# Spectrum ハイウェイ プライバシーポリシー

最終更新日: 2026 年 11 月 20 日（v2.23: 渋滞情報の取得に道路の流れの情報を追加）

Spectrum ハイウェイ（以下「本アプリ」）は、再生中の音楽の情報とスペクトラムアナライザーを表示し、走行中の高速道路・有料道路などでは前方の IC・JCT・SA・PA までの距離と到着予定時刻を表示するアプリです。本アプリが扱う情報と、その使い方は次のとおりです。

## 1. 端末の中だけで使う情報

| 情報 | 使い方 |
|---|---|
| 位置情報（GPS など） | 走行中の道路と進行方向を判定し、前方の施設までの距離・到着予定時刻を計算します。走行中は、画面を消しても計算を続けるために常駐サービスで位置情報を使います。Android Auto だけで使っているときは、車との接続が切れてから約 3 分後（設定で変更できます）に、位置情報の取得を自動で止めます。 |
| 端末のセンサー（ジャイロ・加速度・方位） | 進行方向の判定とトンネル内の位置推定に使います。 |
| 車両の情報（Android Auto 接続時。車速・ETC カードの状態・燃料／電池残量・車両のジャイロや位置） | 速度・位置の推定、ETC カード未挿入の警告、給油・充電の案内に使います。 |
| 運転傾向の学習結果・設定・自分で登録したオービス地点 | 端末内に保存し、到着予定時刻の計算と表示に使います。 |
| 再生中の音（マイクの権限） | 端末で再生中の音の大きさを周波数ごとに解析し、スペクトラムアナライザーとして表示します（解析のために、再生中の音の波形を約 0.2 秒ぶんだけ端末のメモリに置きます。曲の静かな部分・盛り上がる部分を表すために、Android が測る再生中の音の大きさ（実効値・最大値）も使います）。音声の番号を知らせない音楽アプリでは、再生中の音声を見つけるために、端末内の音声ごとに音の大きさだけを短時間測ります。いずれも音声を録音・保存・送信することはありません。 |
| 再生中の曲の情報（通知へのアクセス） | 音楽アプリの再生情報・通知から、曲名・アーティスト・アルバム・ジャケット画像・再生位置を読み取って表示し、再生・一時停止・曲送りの操作に使います。音楽以外の通知の内容は、曲情報の取得元を選ぶ診断画面に表示するだけで、保存しません。 |
| カーナビの案内（通知へのアクセス。ナビのアプリでナビ中のとき） | Google マップ、および Yahoo!カーナビ・moviLink・カーナビタイム・ドライブサポーター・トラックカーナビ・COCCHi・Yahoo!マップ・Waze などのナビのアプリ（通知の種類が「ナビ」のアプリを含みます）が表示している実行中の通知から、次の案内の文（交差点・分岐・出口の名前、路線名、方面）、案内地点までの距離、曲がる方向の矢印の画像を読み取り、案内中かどうかを判定したうえで、音楽の画面に次の案内を表示するためと、前方の経路（JCT の乗り換え先）と降りる IC をナビに合わせるために使います。案内中でない通知（ナビを始めていないときの通知など）は表示に使いません。読み取った内容は保存せず（表示と確認用に最後に読んだ 1 件だけをメモリに置き、ナビが終わるかアプリを終了すると消えます）、端末の外へ送りません。設定の「ナビアプリの連携（Google マップなど）」でそれぞれオフにできます。 |
| 再生中の音声の番号（任意の DUMP 権限） | 利用者が Shizuku などで許可した場合に限り、端末の音声の状態からアプリごとの音声の番号を読み取り、スペクトラムアナライザーの解析対象を選ぶために使います。 |
| 不具合の記録 | 本アプリが異常終了したときに、その時刻・アプリの版・端末の機種と Android の版・エラーの内容（プログラムのどこで止まったか）を端末内に 1 件だけ保存します。車の画面の表示などで失敗した処理も、最近の数十件をメモリに置きます（アプリを終了すると消えます）。位置情報・曲の情報などは含みません。開発者向けの画面で表示・コピー・削除でき、本アプリが端末の外へ送ることはありません。設定の「不具合を報告する」では、この記録と車の画面の動きの記録（1 秒あたりの表示の回数など）・アプリと端末の版を画面に表示し、利用者が「送る」を選んだときだけ、利用者が選んだアプリ（メールなど）に渡します。 |

これらの情報は端末の外へ送信せず、開発者が受け取ることもありません。

## 2. 外部のサービスへ送る情報

本アプリは、次の場合にだけ外部のサービスと通信します。

- **地図データの取得**：地図データ（OpenStreetMap をもとに作成）を GitHub のサーバーからダウンロードします。アプリに同梱した地図データに無い範囲を走るときは、その範囲（現在地の周りの地図の区画。おおよその位置にあたります）を公開の Overpass API のサーバー（OpenStreetMap の地図データを配る第三者のサーバー）に問い合わせて、地図データを受け取ります。
- **渋滞情報（設定した場合のみ）**：利用者が選んだ提供元（TomTom、HERE、Google のいずれか）へ、利用者自身が登録した API キーと、前方の道路の位置（座標。TomTom では、前方の道路にかかる地図の区画の番号と、前方の道路上の数か所の座標も）を送り、渋滞・事故・通行止め・道路の流れ（速さ）の情報を受け取ります。設定画面の「キーを確かめる」では、利用者の位置ではなく決まった地点（東京都心の首都高の区間）の情報を 1 回問い合わせます。送った情報の扱いは各提供元のプライバシーポリシーに従います。

- **Google Play の機能**：Google Play で公開した版では、新しい版があるときのアプリ内アップデートと、評価（レビュー）の画面を、Google Play の機能を使って表示します。これらは Google Play が処理し（[Google のプライバシーポリシー](https://policies.google.com/privacy)）、開発者が利用者の情報を受け取ることはありません。内部アプリ共有などで配布する版では使いません。

これらの通信はすべて暗号化（HTTPS）されます。氏名・メールアドレス・端末の識別子などを本アプリが送ることはありません。送った位置の情報を本アプリが端末の外に保存することはなく、開発者が受け取ることもありません。

## 3. 広告・解析

本アプリは広告を表示せず、利用状況の解析ツールやクラッシュ報告ツール（外部へ送るもの）も組み込んでいません（不具合の記録は端末内だけに残します。1 章）。

## 4. 保存と削除

情報はすべて端末内（本アプリの保存領域）に保存されます。本アプリをアンインストールすると削除されます。渋滞情報の API キーは、設定画面からいつでも削除できます。

- **端末のバックアップ**：本アプリの設定（渋滞情報の API キーを含みます）・スペクトラムアナライザーの表示の設定・自分で登録したオービス地点は、Android のバックアップ機能の対象です。端末の設定でバックアップが有効な場合、利用者の Google アカウントにバックアップされ、アプリの入れ直しや機種変更のときに戻ります（バックアップの扱いは Google のポリシーに従い、開発者が受け取ることはありません）。位置情報・曲の情報・地図データはバックアップしません。バックアップは端末の設定でいつでも無効にできます。
- **設定の書き出し**：設定画面の「設定の引き継ぎ」で、上と同じ内容を、利用者が選んだ保存先へファイルとして書き出せます（API キーを含めないこともできます）。書き出したファイルは利用者が管理し、本アプリが外へ送ることはありません。

## 5. 権限について

本アプリは、最初に起動したときに使う情報と権限を説明し、同意したあとで Android の権限の確認を表示します。どの権限も、端末の設定 → アプリ →「Spectrum ハイウェイ」→「権限」からいつでも取り消せます（取り消すと、その権限を使う機能が使えなくなります）。

## 6. お子様の利用

本アプリは自動車を運転する方に向けたものです。13 歳未満のお子様を対象としておらず、お子様の情報を意図して扱うことはありません。

## 7. このポリシーの変更

本ポリシーを変更したときは、このページの内容と最終更新日を改めます。大きな変更（扱う情報や送り先が増えるなど）があるときは、アプリの更新の説明でもお知らせします。
